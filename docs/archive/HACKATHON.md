# PassPilot — חבילת הצגה להאקתון

## הבעיה במשפט אחד

סטודנטים שצריכים לעבור מבחן Python מבזבזים זמן מוגבל על לימוד רחב ופסיבי, בלי לדעת אילו פערים באמת מונעים מהם להגיע לציון עובר.

## הפתרון במשפט אחד

PassPilot הוא בוחן אדפטיבי בדפדפן שממפה חולשות בזמן אמת והופך אותן לתוכנית תרגול ממוקדת בדרך לציון עובר.

## תסריט דמו — 3 דקות

1. **0:00–0:20 — מציגים את האתגר:** פותחים את [הדמו החי](https://swissystem7.github.io/PassPilot/) ומסבירים שהמטרה אינה לכסות את כל הקורס, אלא לזהות מהר את הנקודות שחסרות כדי לעבור.
2. **0:20–0:40 — בוחרים מסלול:** מסמנים כמה נושאי Python, בוחרים 5 שאלות ורמת קושי, ולוחצים על **„מתחילים בבוחן”**.
3. **0:40–1:30 — פותרים שאלה:** בוחרים תשובה ומציגים את המשוב המיידי, ההסבר והמעקב אחר זמן התשובה.
4. **1:30–2:10 — מדגימים התאמה אישית:** עונים על עוד כמה שאלות, כולל תשובה שגויה, כדי שהמערכת תזהה נושא חלש.
5. **2:10–2:40 — מציגים תוצאה:** מסיימים את הבוחן ומראים את הציון, רמת המוכנות, רשימת החולשות ותוכנית התרגול שנבנתה מהביצועים.
6. **2:40–3:00 — מציגים מצב מבחן:** חוזרים למסך הראשי, פותחים **„מצב מבחן אפקה 10016”**, ומראים תרגול כתיבת קוד לפי מבנה המבחן האמיתי.

## הטכנולוגיה בשורה

אפליקציית Web עצמאית ב־HTML, CSS ו־JavaScript, ללא תלויות וללא שרת, המתארחת ב־GitHub Pages.

## השוק והפוטנציאל

- קהל היעד הראשוני הוא סטודנטים בקורסי מבוא לתכנות שצריכים להגיע לטווח מעבר של **50–61** בזמן הכנה מוגבל.
- המוצר הופך מאגר שאלות לכלי אבחון ותוכנית פעולה אישית, ולכן ניתן להתאים אותו לקורסים, מוסדות ושפות תכנות נוספות.
- אפס תלויות והפעלה ישירה בדפדפן מאפשרים הפצה מהירה למרצים, מרכזי תמיכה וסטודנטים ללא עלות תשתית ייעודית.

## מה הלאה

1. לייבא מבחנים קודמים ולמפות אוטומטית נושאים, ניקוד, קושי ותלויות.
2. להוסיף היסטוריית סימולציות וגרף שמציג את ההתקדמות לעבר ציון עובר אמין.
3. לשלב מחולל שאלות דומות ובוחן AI ממוקד לשחזור טעויות.


## הרחבת קהל המטרה

בנוסף למיקוד המקורי בסף מעבר (50-61), PassPilot מיועד גם לסטודנטים שרוצים להשיג לציון יעד אחר (למשל 85+, לצורך מיצוב אקדמי). המנוע המרכזי - **תכנון למידה מבוסס מרחק ממטרה, לא מכיסוי חומר** - רלוונטי לכל סטודנט, לא רק למי שנמצא בסף מעבר. בדמו נציג שתי דוגמאות use-case שונות: סטודנט בסף מעבר וסטודנט שמכוון ל-90+.

## מקורות דאטה עתידיים

קיים נתוני Open Data ישראליים על מעברי קורסים אקדמיים (למשל נתוני המועצה להשכלה גבוהה ווועדות על אתרי מוסדות לימוד), שיכולים לשמש כבסיס לאימות הטענה של המותג. בנוסף, מתוכנן סקר פנימי קצר בקרב 15-20 סטודנטים במכללה לבדיקת זמן תכנון למידה נוכחי פעיל על מנת לולידציה.
